## 2. 数据与信息要求

对每个品种，请基于**当前交易日期**的公开信息，给出：

- **当日主力合约代码**（例如：lc2601、SI2602、Rb2605 等）
- **最新价**：尽量使用当日收盘价或最近一笔成交价，并标明“截至日期和大致时间”（例如：“截至 [日期] 收盘”）
- **技术面**：参考最近 1–5 个交易日的
  - K 线形态（趋势、多空排列、箱体/突破、是否出现长上影/长下影/顶背离/底背离等）

  - 成交量与持仓变化（放量/缩量、增仓/减仓）
- **消息面/基本面**：引用**最新 3–5 日内**与该品种相关的
  - 宏观政策、产业政策
  - 供需变化（产量、库存、进出口、装置检修/复产、产线冷修等）
  - 行业新闻和机构日评（特别是针对碳酸锂的锂矿拍卖、多晶硅的排产数据等） 并在每一条技术面和消息面信息后用“日期 + 消息源（网站/机构名称）”的形式简短注明。

## 3. 策略输出格式（表格形式）

请最终输出一个**Markdown 表格**，每一行一个品种，列包含：

- **品种及主力合约**（含合约号，例如：碳酸锂 lc2601）
- **方向**（做多 / 做空 / 震荡偏多 / 震荡偏空 / 观望）
- **最新价**（注明日期，例如：“最新价 xxxxx 元/吨，截止 [日期] 收盘”）
- **合理价值区间**（综合宏观面给出实际上的合理价值范围）
- **参考开仓价区间**（给出一个合理区间，并说明是逢高空还是逢低多）
- **目标价**（可以给一个或两个阶段目标，例如“第一目标…，第二目标…”）
- **止损价**（给出明确价位或条件）
- **技术面简述**（2–3 句话，包含：趋势、关键支撑/压力、均线和量价要点，并附日期、消息源）
- **消息面/基本面简述**（2–3 句话，总结供需、政策、宏观或行业变化，并附日期、消息源）
- **交易确定性评级**：在以下等级中选择其一，并简单说明理由：
  - **高**：趋势明确、技术与基本面共振，风险相对可控
  - **中**：有一定优势，但存在较大扰动因素
  - **低**：信号矛盾或波动极大，仅适合轻仓或观望

交易确定性一列请写成：

> “高 / 中 / 低 + 一句简短理由（例如：‘多空共振，趋势清晰’ 或 ‘消息面与技术面分化’）”。
