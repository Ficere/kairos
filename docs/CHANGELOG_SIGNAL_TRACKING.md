## 更新内容

### 新增章节：2. 交易信号追踪与管理

在 `docs/deep_research_template.md` 中新增了完整的交易信号追踪体系，包含以下四个子章节：

#### 2.1 做多信号追踪
- **追踪表格**：记录每个做多信号品种的完整信息
  - 品种名称和合约
  - 信号状态（🟢观察中 / ✅已确认 / ⚠️减弱 / ❌已失效）
  - 触发时间
  - 信号强度（强/中/弱）
  - 触发条件
  - 技术指标状态
  - 后续验证情况
  - 持续时间

- **信号状态说明**：明确定义四种信号状态的含义
- **信号强度评估标准**：提供客观的强度评估依据

#### 2.2 做空信号追踪
- 与做多信号追踪结构相同
- 专门追踪做空机会的生命周期

#### 2.3 多空信号对比分析
要求AI完成以下三个维度的对比：

1. **多空力量对比**
   - 做多信号数量 vs 做空信号数量
   - 强信号占比对比
   - 市场整体偏向判断

2. **信号冲突处理**
   - 识别同时出现多空信号的品种
   - 分析冲突原因
   - 给出处理建议

3. **优势方向判断**
   - 判断当前市场环境下的优势方向
   - 推荐重点关注的方向和品种

#### 2.4 历史信号回顾
- **历史信号表格**：回顾近5个交易日的信号表现
  - 日期、品种、信号类型
  - 触发价、当前价、盈亏幅度
  - 准确性评价
  - 经验总结

- **历史信号统计**：
  - 近5日信号总数
  - 准确信号数和准确率
  - 平均持续时间
  - 主要失效原因总结

## 使用方式

1. **运行分析**：
   ```bash
   uv run kairos-analyze --all
   ```

2. **查看生成的提示词**：
   打开 `plans/deep_research_YYYY-MM-DD.md`

3. **复制到AI助手**：
   将完整内容复制到 ChatGPT、Claude 等 AI 助手

4. **AI将自动完成**：
   - 填写做多/做空信号追踪表格
   - 进行多空对比分析
   - 回顾历史信号表现
   - 提供完整的交易策略表格

## 优势

1. **系统化追踪**：从信号触发到失效的完整生命周期管理
2. **状态可视化**：使用emoji图标直观展示信号状态
3. **强度评估**：客观的信号强度评估标准
4. **历史回顾**：通过历史数据提升决策质量
5. **多空对比**：全面了解市场力量对比

## 注意事项

- 模板优化不影响技术分析本身，只增强了AI分析的结构化程度
- 历史信号回顾需要手动维护（AI会根据上下文推断）
- 建议每日保存生成的分析结果，便于后续对比
